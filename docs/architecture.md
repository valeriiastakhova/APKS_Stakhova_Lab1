# Архітектура AI-агента

1. **Які проблеми вирішує агент:** Автоматизує рутинні процеси створення структури проєкту, налаштування конвеєра складання (npm) та тестування (Vitest), а також створення CI-скриптів для GitHub Actions.
2. **Які skills він використовує:** 
   - `project-scaffold` (створення структури проєкту).
   - `build-and-test` (налаштування системи збірки та тестів).
   - `github-actions` (генерація CI workflow).
3. **Які commands доступні:** `git-init`, `create-project`, `create-build`, `create-actions`, `check`, `init` (оркестратор).
4. **Які дані передаються:** Назва проєкту, обрана мова (TypeScript) та фреймворк тестування (Vitest).
5. **Обробка помилок:** Оркестратор зупиняє виконання команд, якщо попередній крок завершився з помилкою або не створив очікуваних файлів.
