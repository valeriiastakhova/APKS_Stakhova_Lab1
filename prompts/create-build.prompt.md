# Command: create-build

**Передумови:** Наявний проєкт `create-project`.
**Дія:** Виконай навичку `build-and-test` для додавання npm scripts та тестів Vitest.
**Очікувані файли:** `src/math.ts`, `tests/math.test.ts`, оновлений `package.json`.
**Помилка:** Якщо Vitest не додано в залежності, повідомити користувача.
